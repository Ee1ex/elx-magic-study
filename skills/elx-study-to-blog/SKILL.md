# 书屋转博客

用户可以说「把书屋那篇关于主题笔记的资料写成给初学者看的博客，配一张解释图，先看草稿」。默认终点是本地可阅读的文章页。单纯收藏、搜索和整理资料由魔法书屋处理。

## 选一篇可以核对的笔记

使用同级的 `elx-magic-study` 及其现有飞书绑定。以下命令从本 Skill 根目录执行，其他安装位置可用 `--study-root <魔法书屋目录>` 指定；多库使用 `--library <编号>`。首次连接或账号变化按魔法书屋的引导处理。

```text
node scripts/source.mjs search --query "主题笔记" --limit 5
node scripts/source.mjs fetch --id <上一步返回的索引编号>
```

索引编号来自真实搜索结果。核对目标标题和正文；遇到同名或影响写作方向的歧义再请用户选择。读取 `coverage`、版本或采集时间，外部收藏标明快照时间。仅存链接时先取得可用正文或请用户补材料。用户明确接受历史快照时才使用 `--offline`。草稿阶段的取材回执留在本地私人位置。

## 编辑和配图

先用一句话确定读者读完能做什么，再决定开头、例子和段落顺序。保留来源适用条件，分清作者观点、用户已验证的经验和编辑举例。可参考目标博客已发表的同类文章。收藏理由可帮助选题；私人备注、内部链接、操作标记、账号或文档编号留在书屋。引用优先用可公开的原文链接。标题、小标题或步骤旁可以放贴切的 emoji；文字本身应能表达含义，技术术语和 slug 保持清晰。

判断哪段内容仅靠文字较难理解。用户要求配图，或一幅图能解释关键关系时，按[配图指南](references/illustrations.md)**直接调用宿主提供的图片生成模型**，检查实图后放入博客项目。用户已给出的可公开原图也可以使用。用图的位置、图注和替代文本随文章一起编辑。

## 输出并本地预览

按 [Eelex Blog 的 MDX 约定](references/eelex-mdx.md) 准备稿件。用户只要 MDX 时直接交付稿件和已有配图，并标明验证范围。需要本地预览时，把草稿放入博客预览工作树；已有同名稿件先核对是否同一篇修订。用当前仓库的内容校验、测试和实际文章页验收，核对桌面和窄屏的标题、正文、目录、配图及出处。交付本地预览地址、MDX、图像位置和验证结果。线上发布按用户的另一项明确指令办理。
