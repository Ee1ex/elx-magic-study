# {{知识库名称}}

> 📚 **把好资料放进来，需要的时候找出来。**

这里是文章、视频、评论和实践经验的个人书架。魔法书屋帮你记重点、分分类、留出处；下次学习或做项目时，再把有用的知识找回来。

**你仍然可以直接在飞书阅读和编辑。** 魔法书屋是一份给 AI Agent 使用的“小手册”（Skill），不是另一个笔记平台。

## 🌱 三步开始使用

| 步骤 | 你做什么 | 小助手做什么 |
|---|---|---|
| ① 放进来 | 给链接、文档或已经验证的经验 | 读取材料，说明读到了多少 |
| ② 整理好 | 看预览，调整分类、标题或重点 | 记要点、留出处，确认后保存并回读 |
| ③ 随时问 | 带着新问题或项目需求来问 | 找相关资料，解释哪些能用及为什么 |

## 💬 功能与提示词速查

在能识别 Skill 的 AI 对话中复制下面的话，把「这份资料」换成你的链接或正文即可。

| 我想做什么 | 可以直接这样说 |
|---|---|
| 📥 先收藏 | 用魔法书屋先收藏这个链接，备注是……，正文以后补。 |
| 📝 总结文章 | 整理这篇文章，重点讲方法、适用条件和限制，保留来源。 |
| 🎬 整理视频 | 总结这个视频，保留关键时间点，说明字幕和画面的读取范围。 |
| 💭 整理评论区 | 总结这篇笔记的评论区，区分作者回复和其他人的经验，说明实际读取数量。 |
| ⚖️ 比较多份资料 | 把这几份材料一起整理，看看共识、分歧和各自条件。 |

**也可以明确调用：**「用 $elx-magic-study 帮我整理这份资料。」

## 🗂️ 笔记会怎么整理

**先复用已有分类，确实缺少时再新建；一份资料只保留一份主笔记。**

标题采用 **具体内容概括丨末级分类**，概括优先约8字、最多10字符，并保留品牌、产品或方法对象。

> 示例：**OPPO耳机耳帽选购丨数码与音频**

原始标题、作者和来源链接放在正文。保存前可以直接说「换个书架」「标题再具体一点」「去掉这个标签」。

## 🧰 可选功能，需要时再配置

- **核心环境**：支持 Skill 的 AI Agent、Node.js 22+、官方飞书 CLI 和本人授权。
- **外部读取**：「检查能否读取这个平台，缺什么先告诉我。」已有工具优先；缺 OpenCLI 时用 OpenCLIApp 配置 CLI、Agent Skills 和浏览器连接。Agent Reach 按其他需求另选。
- **分类图标**：「给本次新增分类推荐图标，先让我确认。」需要 Agent 实际具备界面操作能力。
- **定时检查**：「每周一早上九点检查新资料，上海时区，先生成草稿。」需要宿主支持、你确认并实际注册；默认不自动改写飞书。
- **按需配置**：只处理飞书或你提供的正文，无需配置全部外部工具。密码、Cookie、密钥不粘贴到聊天。

## ✅ 保存前后，你始终看得清楚

**读取资料 → 预览分类与内容 → 你确认或调整 → 写入 → 回读并返回链接**

- **没有读到，不补猜。** 仅链接、部分评论、字幕和未核验画面会明确标注。
- **草稿不等于已保存。** 回读通过才说已存入飞书；结果未知先查证，不重复建页。
- **旧知识要结合当前情况。** 原文观点、个人经验和 AI 推断分别说明，重要结论回到来源核对。
- **可选功能不默认启用。** 额外安装、权限、删除和迁移另行确认；密码、Cookie、密钥不粘贴到聊天。
