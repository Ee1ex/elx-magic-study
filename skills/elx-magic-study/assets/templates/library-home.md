> 📚 **把好资料放进来，需要的时候找出来。**

这里保留链接整理的文章、视频与实践资料，也保留自己手工记录的推荐、清单和备注。魔法书屋帮你记重点、分分类、留出处；下次学习、做项目或寻找推荐时，再把有用的内容找回来。

**你仍然可以直接在飞书阅读和编辑。** 魔法书屋是一份给 AI Agent 使用的“小手册”（Skill），不是另一个笔记平台。

## 🗂️ 笔记会怎么整理

**入口顺序是书屋管理、链接资料、个人记录。先复用已有分类，确实缺少时再新建；一份资料只保留一份主笔记。**

书屋管理最先显示，便于看状态、偏好和待办。链接资料区按主题分类，资料整理、主题综述、实践记录是正文类型；个人记录区通常每类一篇文档、子类用表格，名称、品牌、自己的备注优先，品牌不适用可以省略，其他字段按需要建议。“待整理”仅暂存未完成资料。已有库不自动迁移。

旧库也可以说「检查旧命名和目录层级，先给改名与移动清单，不要直接修改」。

链接资料笔记标题采用 **具体内容概括丨末级分类**，概括优先约8字、最多10字符，并保留品牌、产品或方法对象。个人分类文档按分类取名，不为每个条目新建一篇。

> 示例：**OPPO耳机耳帽选购丨数码与音频**

原始标题、作者和来源链接放在正文。保存前可以直接说「换个书架」「标题再具体一点」「去掉这个标签」。

## 🧰 可选功能，需要时再配置

- **核心环境**：支持 Skill 的 AI Agent、Node.js 22+、官方飞书 CLI 和本人授权。
- **外部读取**：「检查能否读取这个平台，缺什么先告诉我。」已有工具优先；缺 OpenCLI 时用 OpenCLIApp 配置 CLI、Agent Skills 和浏览器连接。Agent Reach 按其他需求另选。
- **分类图标**：「给本次新增分类推荐图标，先让我确认。」需要 Agent 实际具备界面操作能力。
- **定时检查**：「每周一早上九点检查新资料，上海时区，先生成草稿。」需要宿主支持、你确认并实际注册；默认不自动改写飞书。
- **按需配置**：只处理飞书或你提供的正文，无需配置全部外部工具。密码、Cookie、密钥不粘贴到聊天。

## ✅ 保存前后，你始终看得清楚

**读取资料 → 预览分类与内容 → 你确认或调整 → 写入 → 回读并返回链接**

向已有唯一文档／表格说“帮我记录”就是这条新增的授权，展示后直接保存并回读；首次新增分类、文档、表格或列结构先确认。自己的备注保留原话，网上补查另标来源和日期，推荐结果不自动入库。

- **没有读到，不补猜。** 仅链接、部分评论、字幕和未核验画面会明确标注。
- **草稿不等于已保存。** 回读通过才说已存入飞书；结果未知先查证，不重复建页。
- **旧知识要结合当前情况。** 原文观点、个人经验和 AI 推断分别说明，重要结论回到来源核对。
- **可选功能不默认启用。** 额外安装、权限、删除和迁移另行确认；密码、Cookie、密钥不粘贴到聊天。
