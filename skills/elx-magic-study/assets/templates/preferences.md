# 个人整理偏好

请填写表格的“用户填写”列；空白表示沿用默认规则。小助手每次整理先读这里，偏好改变后会询问是否需要重新整理旧资料。默认说明只作参考，不作为你的选择。

| 偏好项目 | 用户填写 | 默认说明 |
|---|---|---|
| 重点领域 | | 按本次材料内容判断，不凭标题猜测 |
| 分类习惯 | | 优先复用现有内容主题，必要时预览新分类 |
| 标题细节 | | 具体对象与内容概括约8字，最多10字符，再加丨末级分类 |
| 总结重点 | | 核心观点、适用条件、行动建议及来源 |
| 展示风格 | | 简短段落配表格，避免长篇堆砌 |
| 默认读取范围 | | 如实区分全文、节选、字幕、评论及未覆盖部分 |
| 偏好变化后提醒整理 | | 询问先预览、稍后或不整理；不自动修改旧文档 |
| 补充说明 | | 可写希望强调的对象、避免的写法 |

偏好用于内容整理，不能授权删除、搬迁、发布或权限变化。若与已确认写入预览冲突，小助手会重新生成预览。
