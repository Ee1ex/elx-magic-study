# 按需 HTML 知识图谱

用户说“给我看看知识图谱”“看看这个主题和其他资料的关系”时，实际生成并展示图谱，不仅讲方法。

1. status 查看当前索引覆盖和上次更新时间。无索引时先 sync；索引未覆盖全部库时明确说明，不能称为全库图谱。
2. graph --output 指向本次项目或用户指定位置的一个新 HTML 文件。文件名使用日期／时间避免覆盖。
3. 用户只看一个主题时，可先检索并读取相关页面；目前脚本以全索引为输入，可在图中搜索和聚焦邻居。超过 limit 的节点会明确标记省略，不能把截断图当完整图。
4. 用宿主 open_in_codex、浏览器或文件预览打开实际文件，并给本地可点击链接。离线单文件不需要网站发布、服务器或 CDN。
5. 告诉用户可以拖动、缩放、按类型筛选、搜索、点击节点查看证据与原文。侧边节点列表也能操作，减少对鼠标拖动的依赖。

连线来自正文 HTTP(S) 链接，以及带 evidence 的明确关系。未索引引用显示为范围缺口，不认定断链。默认不画由 AI 猜测的语义边，也不把布局距离解释为相似度。

图谱只嵌入标题、摘要、来源链接和必要关系，不嵌入全文。即便如此也可能涉及私人内容，默认仅本地展示；公开分享或上传前确认范围。脚本不发送网络请求，原文链接只有用户点击才打开。

demo-import 生成的图必须有“合成资料演示”标记，不可冒充用户真实飞书知识图谱。

## 摘要与正文摘录

图谱优先使用 summaryForHash 与当前正文 hash 一致的 Agent 摘要。无摘要或版本不一致时，提取最多 400 字符的正文，明确标为“正文摘录”；过滤标题、来源元信息、代码围栏和操作标记，没有合适文本就说明缺失。旧摘要保留在本地记录，但不用于当前图谱搜索。

整理计划可在每个 action 提供可选 summary（1—400 字符，描述修改后的整篇页面）。它进入预览与 digest，写后绑定实际核验版本。没有填写则不强制模型调用。正文变更使旧摘要失效；摘录与摘要都只代表当前缓存，不代表刚刚联网核对。
