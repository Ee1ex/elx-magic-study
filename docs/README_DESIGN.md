# README 设计说明

模式：完整 README 改写。面向第一次使用个人知识库 Skill 的用户，不要求先理解数据库、RAG 或命令行。

- 读者：想整理收藏、以后能找回的人。
- 一句话价值：把资料放进书屋，需要时让小助手找出来。
- 直接证据：当前代码生成的合成知识图谱，清楚标记为演示。
- 第一次成功动作：在 Agent 里说“用魔法书屋帮我连接飞书知识库”。
- 视觉主题：温暖的小书屋，资料卡片和真实关系线。

配色沿用项目的米白、深绿，辅以少量淡紫；系统字体；圆角 22；流程 SVG 的主要文字 56 单位，避免手机上缩得太小。README 保留可复制的文字与指令，图片失效也能理解。

使用本地静态流程图和真实合成示例，不生成装饰性人物图、不使用 GIF、不添加访问计数或未经验证的徽章。
