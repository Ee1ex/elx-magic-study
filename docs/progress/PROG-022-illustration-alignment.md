# REQ-027 逐节配图与读图核对

2026-11-21，LEVEL 1。用户要求提升书屋转博客配图的解释力，每个中标题至少有一份有用的配图，并指定一篇飞书笔记进行本地验收。

## 行为

- 每个正文二级标题至少一张本节专图。通用提示词先确定读者的问题与本节答案，再指定可看见的对象、动作、位置或关系，以及容易造成的误解。
- `scripts/check-figures.mjs` 使用目标博客现有 MDX 解析器，按 H2 检查正文图片、非空 alt、本地文件和内容摘要。封面、标题图标、代码块和之前章节重复出现的同一图像不充当本节专图。
- 数量核对和语义验证分开进行。遮住网页标题和图注读图，核对能够据图作出的判断，桌面和窄屏实测每张图能否正确显示。单独安装包版本为 0.2.0。

## 验收

| 项目 | 实际结果 |
| --- | --- |
| 原问题复现 | 老稿有 3 个 H2，只有第一节有正文图。新检查器在修订前返回 1/3 并以非零退出。 |
| 正常取材与试稿 | 通过书屋绑定回读用户指定笔记。新稿 5/5 节有专图，原预览稿修订为 3/3。8 张正文图均用宿主图片模型生成。实际提示词、图片原件和私人回执保留在本地。 |
| 独立读图 | 独立模型只读图片复述关系。把难以解释的知识示例重画为可比较的前后帧，校正另一张图中指标与定位问题的关系；对修订结果再次盲读。这是模型读图验收。 |
| 页面检查 | 1440 与 390 像素宽度下，两篇均可从首页进入，8 张正文图逐一成功解码，各节来源和 alt 已核对。额外制作了适合卡片裁切的宽屏封面。 |
| 回归与本地包 | CLI 117 项、MCP 5 项、文件转换 7 项、博客 46 项通过。博客静态构建通过，保留基线的 4 条 lint 警告。两份 Skill 格式通过，独立安装、ZIP 解包以及用解包脚本检查两篇文章均经过验证。 |

本轮交付为本地预览与本地包。真实飞书内容、对象编号和媒体 token 均留在私人工作区。
