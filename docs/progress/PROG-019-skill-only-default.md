# PROG-019 Skill-only默认入口（REQ-024）

2026-10-16。用户要求直接安装Skill时保留MCP入口和可选提示，但不默认安装或启用，避免harness用户额外窗口和重复确认。

## 实现
- Skill入口从“已配置MCP优先”改为默认CLI；工具可见、旧配置或包存在不作为切换授权。
- MCP参考、首次导览、连接指引、README与MCP安装说明统一：仅用户明确选择时处理相应安装／配置／启用／使用范围。
- 已有明确使用选择可沿用，不反复追问；禁用设置不自行恢复。普通Skill任务不打开MCP配置／批准窗口。
- 保留安装入口和MCP写入批准，未知操作仍沿原operation查证，不通过切换入口绕过。
- 安装脚本本来只复制Skill，未修改运行时代码、全局安装或客户端设置；本轮不打包发布。

## 验证
- 实际安装器在独立测试目录安装48文件；第二次返回already-identical。仅产生skills目录，预置测试config.toml逐字节不变，真实Codex配置也不变，无MCP安装产物。
- Skill Creator格式检查、相对链接及git diff --check通过。
- 人工流程走查：新用户直接使用CLI；仅发现MCP时不切换；用户明确要MCP时进入安装说明；已有明确选择可沿用；已禁用不启用；未知写入不换入口重发。这不是独立Agent或各harness实测。
- 原始隔离验证位于忽略目录artifacts/verification/req024。跨宿主自动选择与实际窗口体验仍需使用反馈，不声称所有harness通过。
