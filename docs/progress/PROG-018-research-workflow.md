这是本次作者按指引进行的流程走查，不是独立Agent评测或真实保存测试。

| 合成用户请求／条件 | 走查得到的处理 |
|---|---|
| “只收藏这个链接，先别展开” | 原收藏流程，不跨平台搜索；有唯一目标时沿原授权保存 |
| “保留我的耳机备注，顺便比淘宝京东价格”但缺规格 | 先问影响比较的规格；可先读已有条目，不把不同款列表价排成价格榜，不覆盖原备注 |
| “先查B站和小红书评价，暂不入库” | 两平台分别报告覆盖；B站字幕缺失时不虚构视频内容，不调用capture／plan或管理同步 |
| “推荐库内两项和网上新候选” | 分列两组，核对原文和筛选条件，不自动写回 |
| “记录到现有唯一表格；价格放备注，不扩列” | 展示原备注和带出处补充后沿单条授权；MCP入口仍须既有终端批准，不借新指引跳过 |
| 评论为空、统计为0、搜索有旧帖 | 报实际覆盖和字段异常；不推断无评论、无互动或最新趋势 |
| Exa未连接、平台要求登录、需要云转写费用 | 说明具体缺项；继续独立且已授权的读取，不静默替换指定工具或开通付费服务 |
