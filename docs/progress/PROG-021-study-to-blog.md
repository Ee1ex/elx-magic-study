# REQ-026 书屋转博客

2026-11-21，LEVEL 1。本地交付同仓可选 Skill、经过回读的单篇博客草稿、生成插图及预览。真实笔记、账号信息、取材回执和预览证据留在私人工作区。

## 实现

- `skills/elx-study-to-blog` 有独立入口、宿主描述、取材脚本、MDX 规范和图像指引。安装器通过 `--skill elx-study-to-blog` 单独选择它，默认安装目标仍为魔法书屋。先核对副本各文件再放入宿主技能目录，已有不同版本保留。
- 取材脚本只转交搜索和正文读取，复用已有书屋的账号、绑定、范围和缓存。默认发现并列安装，也能显式指定魔法书屋目录。标题或私人收藏理由命中后仍需核对实际正文。
- 写作区分公开依据、个人做法与编辑举例。参考包含真实站点字段、栏目、图片路径、适量 emoji、宿主图片模型的触发与目视核对。可按用户意图交付单独 MDX 或本地文章页。

## 验收

| 项目 | 结果 |
| --- | --- |
| 安装与取材 | 隔离 Codex 目录内只安装新 Skill 的 5 个文件，指定已有书屋后读回选定飞书笔记全文。并列安装、重复安装、不可用依赖与保护用户修改有合成回归。独立验收另从合成库生成一篇 MDX。 |

| 博客契约 | 在博客独立工作树验证当前 main 基线，为新增文章补上站点地图预期。通过格式、类型、ESLint、46 项测试及静态构建。基线即有 4 个未使用变量警告。 |
| 本地阅读 | Chromium 桌面 1440px、窄屏 390px 实测首页卡片进入详情，图片成功解码、出处及目录可见，页面无横向溢出。 |
| 仓库回归 | CLI 114 项、MCP 5 项和文件导入 7 项通过，两份 Skill 均通过格式验证。 |
