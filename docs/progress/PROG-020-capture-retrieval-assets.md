# REQ-025 收藏检索与图文核验

2026-11-21，LEVEL 1。范围为三项仓库优化、开发指南的版本说明、本地回归及用户确认的一篇飞书测试页。发布与全局安装另行办理。

## 行为变化

- `captureNote` 保存用户收藏理由。`source-content` 更新正文和获取说明，正文哈希继续只覆盖正文。旧版 link_only 记录在首次补正文前可从原占位恢复备注。旧正文里已无可识别原备注时保留缺失状态。
- 检索返回命中途径。仅存链接时可按标题、用户备注、来源网址找到，系统占位文字不作为正文；空正文的索引项可按标题找到。CLI 和已有 MCP fetch 对外部来源给出本地版本、覆盖和时间。飞书文档继续在线核对账号与范围。
- `asset-receipt` 为每个已确认的位置登记目标文档、资源摘要与状态。工作台沿用现有 Base 字段，显示待核验、写入待查证或已核验。已核验图片需要实际查看并核对原生块，PDF 还需要下载摘要匹配。重复登记沿用同一条记录；工作台暂时读不到刚写入的值时，仅有限重读核对。
- 开发指南从根包清单和发布记录获取版本依据。

## 验收结果

| 检查 | 观察 |
| --- | --- |

| 独立使用检查 | 合成库用收藏理由找到外链并读取第二版正文；发现的占位文字误命中已修正，原标题、网址和旧格式备注均可检索。 |
| 完整回归 | CLI 串行 112 项、MCP 5 项、文件转换 7 项全部通过；Skill Creator 格式检查通过。 |
| 真实飞书试点 | 已确认的一篇页面内恰有一个原生图片块、一份 PDF 附件和原正文。官方图片预览显示预期的三种图形，下载 PDF 的 SHA-256 与原件一致。 |
| 工作台与重试 | 初次请求在发送前遇到网络错误，查证步骤仍为 pending 后沿原计划继续。工作台初次回读未匹配，稍后读取已一致。最终总览与两条 Base 记录均显示已核验；重复登记后两个记录 ID、正文版本和总览版本均相同。 |

真实账号、链接、资源 token 和逐次回执仅留私人验证目录。图片视觉检查使用飞书官方资源预览，桌面及移动客户端页面布局仍待分别验收。
