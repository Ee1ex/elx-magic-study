## 实现与证据

- 修改前 38 项基线通过；先增加分类用例，6 项失败，证明缺上下文、分类元数据和边界检查；原有预览替换用例本就通过。
- 新增 classification.mjs：只读读取两层位置和主题候选，校验来源覆盖／证据、标签数量、主题版本和两边原文依据，生成飞书正文中的分类段落。
- 接入 plan/apply/finishPlan；位置和主题变更在发送前阻断。分类来源纳入原有 sourceHash 约束；不另造授权机制。新计划与旧计划互不借用 digest。
- 同一来源在同一批次及已完成后不能再通过分类创建副本；不同预览竞争同一来源也会阻止后来副本。不能把关联主题改写混入分类动作。
- 新增 status／maintenance 的待内容分类列表，区别输入／输出角色待分类。
- Skill 分类工作流与 JSON 例子可按需发现，README 只更新现有文字；未修改图片和版式。
