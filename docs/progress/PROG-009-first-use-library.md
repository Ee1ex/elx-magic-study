# PROG-009 首次专用知识库与分类连续入库

日期：2026-10-04。REQ-015 用户确认实施；空间名最终指定「魔法书屋知识库」。本轮仅源码、测试、文档与本地提交，版本保持0.5.0，不发布或更新安装。

## 实现

- OpenCLI 缺失优先 OpenCLIApp 桌面引导，在应用内安装 CLI 和 Agent Skills，再分别验证宿主发现、浏览器桥接、用户登录及目标内容。Agent Reach 不作为必装前置。
- 新增只读 space-discover：未绑定可用，优先旧绑定，完整分页区分专用空间候选；权限、格式和分页错误不冒充不存在。通过本机官方 CLI 内嵌参考核对 data.spaces、has_more、page_token 协议。
- 新增 library-bootstrap.md：独立空间、确认用途与首页范围、官方 CLI 创建和回读、真实结果绑定、本地初始化记录及未知结果停止；不改变已有绑定。
- create/shelf 与 parentStep 支持同一预览创建必要分类及来源笔记，最多两层。父节点来自前序步骤真实回读；原 payload/digest 不变；shelf 记 navigation。每次入库检查分类，优先复用。
- apply/recover/diagnose 和最终入库元数据解析同一依赖关系；分类名称、正文或路径变动阻断后续操作。部分成功不回滚删除；旧计划保持兼容。
