## 实现

- 新增titleSummary字段与formatNoteTitle：NFKC规范后按Unicode码点限制最多10字符，禁止分隔符／控制字符；分类后缀取已核对的destination最后一级。标题、概括和正文首标题进入同一不可变计划；显式完整title冲突时拒绝，不静默覆盖。
- Agent按约8字目标保留品牌、产品、方法及核心对象；「OPPO耳机耳帽选购」为10字符，「LLM知识库方法」为8字符。不机械凑字或截断，原始标题和出处放正文。
- 命名指引接入新来源入库、分类及模板；旧计划无titleSummary仍兼容，不批量改名。首页模板包含知识库名称、介绍用途、功能与提示词、前置条件、保存及核验说明；新初始化须先预览正文，再填充回读，不重复追加已有指南。
