# REQ-020 两类资料、个人表格记录与双来源推荐

日期：2026-10-13。用户确认前轮方案，并修订：书屋管理最先展示；名称、品牌和用户备注为核心，其他字段按需增加，不设固定分类字段或条目数量门槛。积累资料后由 Agent 检查已有内容并建议扩展列，例如热量和参考价，不自行增加或回填。

## 批准范围

- 本地 Skill 源码、指引、合成验收、文档与仅含本轮文件的本地提交。
- 首页顺序为书屋管理、链接资料、个人记录；分区下按主题组织，旧库继续兼容。分区绑定仅登记已核验对象，不自动移动真实资料。
- 每类个人记录一篇文档，子分类在文档内使用表格。名称必填，品牌与用户备注可空；已有列复用，未知信息不猜测。长段做法、评价与原始链接可留在表格外。
- 用户说“帮我记录”且已有文档与表格目标唯一时直接按本次授权追加并回读；首次新建分类／文档或扩展列先展示预览，一次确认后连续执行。
- 联网补充使用 Exa 插件和 Agent Reach 的适用路由，标明来源、规格、日期与未核实信息；个人记录仍归个人区，不伪造分享链接或实践验证。
- 推荐分别输出知识库已有内容与网上新发现；随机选择先核对条件，再从合格条目池抽取。

## 不在本轮范围

不修改真实飞书或个人状态，不导入用户旧 Markdown，不迁移旧分类，不安装／升级工具或全局 Skill，不打包发布，不调度，不删除历史文件。新增列和旧资料整理只提供建议或预览，不自动执行。

## 实施与验证

1. 两类分区及旧计划兼容：合成节点验证绑定身份、范围、分区变化和主题分类深度。
2. 原生表格追加：失败用例先行，验证动态列、备注保留、重复条目、并发修改、未知结果只读恢复；不以文末 Markdown 行冒充表格新增行。
3. 条目检索与随机：验证分类上下文、字段筛选、抽取范围及缓存边界；联网推荐与是否满足“低卡”等语义条件由 Agent 核对证据。
4. 集中回归、Skill 格式、脚本语法、链接、隐私、Diff 与本地提交。真实表格及平台验收另列待验证。
