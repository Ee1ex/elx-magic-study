## 范围

1. 书屋管理下一个工作台文档及一张多维表格“待办与变更”，同一明细支撑状态、增改预览、异常未入库事项及看板。
2. 每次入库、预览、失败或查证后自动同步指定管理资源；主文章成功与管理同步成功独立，失败仅重试管理更新，不重建文章。
3. 新建用户可填写的个人整理偏好页，每次调用前读当前已知字段；偏好变化提示一次是否重新整理，旧资料仍需具体清单确认；预览后的偏好变化阻断过时写入。
4. 主题更新建议独立于主题正文修改，要求来源／目标版本及双方证据；无证据不凑建议，实际修改另行确认。
5. 管理文档不进入普通资料队列、统计、检索或图谱；保留用户备注、偏好、其他页面和历史操作。

## 实施与验收顺序

合成失败用例 → 脚本／模板及指引 → 现有知识库完整发现与真实初始化 → 文档、字段、视图回读 → 重复同步不重复建记录 → 偏好读写保护与主写入失败边界 → 文档记录和本地提交。
