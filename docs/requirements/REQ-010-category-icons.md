# REQ-010 分类页原生主题图标

日期：2026-10-03。用户确认先做浏览器辅助版。范围为一级和二级分类页；由当前 Agent 根据主题选择飞书选择器中的表情图标，网页设置后刷新核对，不改标题文字或正文。

## 规则

- 新建分类后检查图标；分类内容更新时重新判断主题是否改变，普通导航增补不频繁换图标。
- 无历史记录的已有图标视为用户选择；已由 Skill 设置的图标若与网页当前值不同，包括被移除，视为手动调整并保护。
- 当前主题未变且自动图标仍匹配时保持；主题不明确则待设置，不猜图标。
- 浏览器未登录、无权限、选择器不可用、结果不确定时留待设置，不伪称成功。点“添加图标”可能立即产生随机图标，必须保留操作前观察并完成最终刷新核对。
- 脚本管理建议与回执，不伪造公开API或替代浏览器；实际网页观察由宿主工具提供。新状态不回填旧资料。

## 验收

只读核对分类身份、深度和文档版本；选图规则覆盖默认、手动、自定义图标、相同主题、主题变化和缺浏览器。成功回执需目标一致、刷新后图标一致及本地证据；无证据、旧计划或正文版本变化不得标成功。真实试点仅主题知识，其他分类及宿主差异另验。

不包含：自动读取网页私有接口、改名加Emoji、长期监听、批量普通笔记装饰、发布及安装升级。
