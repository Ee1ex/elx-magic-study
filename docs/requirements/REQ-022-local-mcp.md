# REQ-022 本地 MCP

日期：2026-10-14。用户要求以 [开发计划](../plans/LOCAL_MCP_PLAN.md) 与 [交接](../plans/LOCAL_MCP_HANDOFF.md) 为基础实现可维护、可插拔的本地 MCP，并准备 1.0 版本。沿用 LEVEL 1。当前实现范围为本地源码、合成验收、独立包、Skill 指引与版本准备；真实飞书写入和全局客户端配置不从历史授权推导。

## 成功标准

1. 官方 SDK stdio 握手、工具发现和结构化调用；stdout 只含协议，阻塞飞书操作在异步子进程中。
2. Skill-only 与 MCP 可分别安装；MCP 包含共用核心且不依赖开发仓库路径，同一个 `~/.elx-library` 状态目录保持兼容。
3. 搜索、条目筛选/合格池随机、正文、原生表格、偏好、有界同步、计划、状态和恢复复用现有 CLI 校验、锁及回读。
4. 模型单独掌握 operation/digest 不能触发 apply；本机人工核对完整计划并手动输入批准短语后，产生一次性凭据。重复发送及未知写入必须停止查证。
5. 不提供任意 shell、文件路径、删除、整篇覆盖、远程 HTTP 或自动迁移。MarkItDown 转换作为可选 Skill 能力，MCP 不内嵌 Python 运行时。
6. 合成协议与旧 CLI 回归、独立包启动分别验收；Codex 实际连接及飞书真实保存回读单列，未运行不能标成功。

版本按仓库三段格式命名 `1.0.0`。ELX Level 自动 dry-run 从提交类型计算为 `0.11.0`；本次显式 `1.0.0` 是用户指定的版本目标，发布前仍需核对交付清单与当次确认。
