## 已确认范围与执行检查点

1. 表格回读：只归一化已识别表格分隔行的连字符数量，保留正文、单元格、列数与代码块差异；新写入及旧创建／追加计划恢复适用。验证：等价格式通过、内容变化拒绝、未知结果不重发、原digest不变。
2. Windows OpenCLI：项目内无shell调用入口，安全解析已安装OpenCLIApp或npm入口；保留完整参数，不修改全局工具。验证：含&的签名链接仍为一个参数，不执行材料中的其他命令。
3. 首页URL：已知文档URL复用；裸返回token缺URL时只读查询官方元数据并核对身份、类型与链接。验证：权限失败、错误文档、非法链接停止，不猜域名、不重复创建。
4. 错误诊断：保留有限结构化原因和处理建议，包括data.result/warnings的失败，不打印原始正文、URL、凭据或完整响应。验证：模拟失败可定位，敏感字段不进入错误回执。
5. EPERM：在实际工作区做有界基线与文件替换探针，记录是否复现；没有根因证据不声称修复，不改系统设置。
6. 整理当前SPEC、路线图与待验证口径，历史证据留在既有台账；完成源码、格式、链接和必要回归后本地提交。
