# REQ-016 精细短标题与首页说明书

日期：2026-10-05。用户确认前轮方案，并补充：10字内的概括尽量约8字，保留品牌与对象，示例「OPPO耳机耳帽选购」。

## 目标与范围

1. 新来源笔记采用「具体内容概括丨真实末级分类」。概括优先约8字、最多10字符，字母数字计数；原始标题／出处保留正文。首页和分类页不套用，不自动批量改名旧笔记。
2. 新建首页先有知识库大标题、介绍、用途，之后是Skill功能、可复制提示词、前置条件和确认流程，最后实际导航。完整正文进入初始化预览，不以空页作为完成。
3. 用户批准在已有知识库测试：首页替换模板占位区域、保留导航和历史；指定一篇方法来源笔记按预览改名并同步首标题。正文、链接、目录位置和其他笔记保留。

## 验收与边界

- titleSummary与classification生成完整title，校验长度、分隔符、真实分类、重名；新分类parentStep同样适用。旧计划无新增字段保持兼容。
- 信息量与语义精细程度由Agent核对，不把8字设为必须凑满的最小长度；不在脚本中截断品牌或型号。
- 标题先失败用例再实现，完整串行回归；首页模板按真实现有页面局部替换回读，并核对既有链接与非目标内容。
- 仅源码、测试、文档、本地提交与上述两处真实页面测试；不发布、升级安装、批量迁移或删除文件。私人回执保存在个人目录，不纳入Git。
