# REQ-021 文件转换与关键资源入库

2026-10-14，LEVEL 1。用户要求把MarkItDown能力加入魔法书屋，处理常见文件；链接中的关键图片和PDF原件也纳入飞书整理文档。

## 范围与行为

- 增加本地文件转换入口，复用MarkItDown而不复制整套上游Skill；保留原件、转换正文、摘要和内嵌图片候选。
- PDF/Office/HTML等文字提取与视觉内容核对分开；空正文、扫描件、未读图像不能标为完整。
- 关键图片在整理文档中原生嵌入，PDF原件以附件保存，并保留来源和图注。内容与资源共同预览，分别回读。
- 延用当前官方CLI的富文本路径；现有Markdown plan/apply不扩展资源动作，也不伪装其文字匹配可核验附件。Agent保存独立资源回执，不重发未知写入。
- 本轮为相关本地Skill更新、隔离转换环境、本机备份同步与合成验证。无新云OCR、转写、常驻服务、远端知识库补图、发布、删除或权限调整。

## 验收

实际合成文件PDF/DOCX/PPTX/XLSX/HTML/CSV转换、原件字节保留、Office资源候选、空正文标记、图片不伪装OCR、禁止覆盖输出与不支持格式失败。源码／本机安装一致性与Skill格式核对。原生图片/PDF上传、浏览器显示及附件下载hash需要后续具体资料试点，不能拿CLI语法检查当远端成功。
