# 魔法书屋 1.0.0 · 本地 MCP 与文件整理

1.0.0 提供可选的本地 stdio MCP。13个结构化工具覆盖诊断、文档与个人条目检索、最新正文、原生表格上下文、整理偏好、有界同步、写入预览、操作状态、执行与恢复。MCP 与原 Skill/CLI 共用状态、账号范围、计划、锁和回读；只安装 Skill 的用户可继续使用 CLI。

文件整理加入可选的 MarkItDown 本地转换入口，保留原件和图片候选。关键图片嵌入与 PDF 附件由 Skill 按官方工具流程预览、上传并分别回读；不是 MCP 自动上传功能。修复普通表格单位跨度元数据被误判为合并表格的问题。

MCP 写入需要先生成完整计划，由本机用户在交互式终端核对并输入批准短语。计划摘要或模型声明本身不能授权。未知写入先查原操作，禁止盲目重发；首版不开放删除、整篇覆盖、任意命令或任意文件路径。

**本地验证**：MCP 合成协议与批准边界5项通过；旧 CLI 107项在系统临时同源码副本通过；Skill ZIP 47文件、独立 MCP ZIP 2500文件解包后逐文件 SHA256 一致；解包后的 MCP 完成官方客户端握手与检索测试。

**待验**：实际 Codex 全局配置与飞书文档/表格写入闭环、真实图片/PDF附件上传、其他客户端和 macOS/Linux。工作区旧测试曾遇 Windows 原子重命名 EPERM；临时副本通过不表示该环境问题已解决。请勿将本地合成结果视为真实飞书写入成功。

安装依赖：Node.js 22+、已按用户权限配置的 `lark-cli`、宿主 AI 模型。MCP 包含固定的 Node 运行依赖；MarkItDown Python 运行时按文件转换需要另装。详见 `mcp/README.md`，以及 `artifacts/SHA256SUMS-v1.0.0` 对应的 Release 附件摘要。
